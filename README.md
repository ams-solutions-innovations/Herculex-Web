# Herculex Web — herculex.app

The marketing site for Herculex: landing page, privacy policy, terms, support and account deletion.
Static [Astro](https://astro.build) site, deployed on Cloudflare Pages.

The logged-in **web app** is not here. It is the Flutter app itself, built for the web from the app repo
(`../Herculex`, branch `feature/web`) and deployed to `app.herculex.app`. See `docs/web/ROADMAP.md` there.

## Commands

```bash
npm install
npm run dev          # http://localhost:4321
npm run build        # → dist/
npm run preview      # serve dist/
npm run sync-legal   # copy privacy policy + terms from the app repo
```

Node ≥ 22.23.4 (Astro 7). `.node-version` pins 24 for Cloudflare.

## Design system

The site uses the app's design system 1:1, so the page and the app look like one product:

| Here | Source in the app repo |
| --- | --- |
| `src/styles/tokens.css` — colours (Classic Blue, dark + light), radius, spacing, motion, glass | `lib/design_system/tokens/hx_colors.dart`, `hx_geometry.dart`, `hx_motion.dart`, `components/hx_glass.dart` |
| `src/styles/global.css` — type scale, `.hx-card`, `.hx-pill`, `.hx-btn`, `.hx-frosted`, `.hx-glass` | `lib/design_system/theme/app_theme.dart`, `components/hx_card.dart`, `hx_pill.dart`, `premium_button.dart` |
| `src/components/Icon.astro` — Material Icons by Flutter name (`fitness_center_rounded`) | `Icons.*` |
| `src/components/mockups/*` — dashboard, active workout, nutrition diary, cards | the matching widgets, at 1 CSS px = 1 dp |
| `public/fonts/*.woff2` — Manrope + Space Grotesk (OFL) | `assets/fonts/` |

If a token changes in the app, change it in `tokens.css` too.

## Generated files

- **Legal pages** — `src/content/legal/*.md` are generated from the app repo's `docs/PRIVACY_POLICY.md` and
  `docs/TERMS_OF_SERVICE.md` by `npm run sync-legal`. Edit the originals, then re-run the sync and commit.
- **Training techniques** — `src/data/set-types.ts` feeds `/training-techniques` and the landing-page section. It
  mirrors the app's `SetTypeInfo.all` (`lib/features/workouts/presentation/widgets/set_type_menu.dart`: ids,
  badges, colours, volume and CNS factors). When a set type changes in the app, change it here too.
- **Brand assets** — fonts, icons, the OG image, avatars and exercise art in `public/` are generated by
  `scripts/build-assets.py` (needs `fonttools`, `brotli`, `pillow`):

  ```bash
  python scripts/build-assets.py "../Herculex"
  ```

## Deploy (Cloudflare Pages)

1. Pages → Create project → connect this repo, project name `herculex-site`.
2. Build command `npm run build`, output directory `dist`. Node comes from `.node-version`.
3. Custom domain `herculex.app`. Add a Redirect Rule `www.herculex.app/*` → `https://herculex.app/$1` (301).

`public/_headers` sets a strict CSP (`script-src 'self'` — keep scripts in `public/scripts/`, not inline) and
long-lived caching for hashed assets. `public/_redirects` sends `/app` and `/login` to the web app.
